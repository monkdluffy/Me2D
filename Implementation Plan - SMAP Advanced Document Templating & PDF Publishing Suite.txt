# Implementation Plan - SMAP Advanced Document Templating & PDF Publishing Suite

Build a standalone, high-performance, cross-platform (Windows & macOS) desktop application using Python and **Flet** (Flutter-backed engine) to replace legacy MS Word VBA macros with an advanced batch templating, 78-variable canonical injection, dynamic image asset handling, and automated PDF conversion/post-processing engine.

---

## User Review Required

> [!IMPORTANT]
> **Key Architecture Decisions for Review**:
> 1. **Cross-Platform PDF Conversion Engine**:
>    - Primary converter: **LibreOffice Headless** (`soffice --headless --convert-to pdf`). Autodetect installation on macOS (`/Applications/LibreOffice.app/Contents/MacOS/soffice`) and Windows (`C:\Program Files\LibreOffice\program\soffice.exe` or `C:\Program Files (x86)\...`).
>    - Windows Fallback: Native **MS Word COM Automation** (`win32com.client`) if LibreOffice is not installed but Microsoft Word is available.
> 2. **78 Canonical SMAP Variables Input Matrix**:
>    - Categorized into 4 expandable, styled accordion/tab sections: Data Badan Usaha, Personil/Staf SMAP, Logbook & Audit Dates, and Rekan Bisnis.
> 3. **Image Asset Management**:
>    - Supports dynamic image upload for Logo (`{{logo_bu}}`), Stamp (`{{stempel_bu}}`), and Signatures (`{{ttd_direktur}}`, `{{ttd_fkap}}`, `{{ttd_rekan}}`, `{{stempel_rekan}}`, etc.) with customizable millimeter-based dimensions (`InlineImage`).
> 4. **Batch Concurrency**:
>    - Multi-threaded processing via `concurrent.futures.ThreadPoolExecutor` ensuring responsive Flet GUI with live progress bar and status console logging.

### Core Document & PDF Engine Modules

#### [NEW] [core/__init__.py](file:///e:/@Medi/@002 Gemini Projects/@0001_canido_doc_manager/core/__init__.py)
- Expose core engine interfaces.

#### [NEW] [core/doc_engine.py](file:///e:/@Medi/@002 Gemini Projects/@0001_canido_doc_manager/core/doc_engine.py)
- Primary engine built on `docxtpl` (`DocxTemplate`), `python-docx`, and `Jinja2`.
- `process_document(template_path, output_path, context, image_map)`:
  - Parses Jinja placeholders across Body, Headers, Footers, and Tables.
  - Dynamically converts uploaded image file paths into `docxtpl.InlineImage` objects with specified millimeter width/height.
  - Sanitizes legacy raw `{variable_name}` and `${variable_name}` tags using paragraph/run XML traversal to resolve MS Word split-run XML issues.
  - Returns metadata on replacements applied and handles errors cleanly.

#### [NEW] [core/pdf_engine.py](file:///e:/@Medi/@002 Gemini Projects/@0001_canido_doc_manager/core/pdf_engine.py)
- `convert_docx_to_pdf(docx_path, output_pdf_path, libreoffice_path=None)`:
  - Autodetects LibreOffice executable across Windows (`C:\Program Files\LibreOffice\program\soffice.exe`) and macOS (`/Applications/LibreOffice.app/Contents/MacOS/soffice`).
  - Fallback to Windows COM Automation (`win32com.client.Dispatch("Word.Application")`) when running on Windows without LibreOffice.
- `apply_pdf_watermark(pdf_path, output_pdf_path, watermark_text, opacity, angle, font_size, color_rgb)`:
  - Uses `fitz` (PyMuPDF) to overlay semi-transparent diagonal watermarks across all pages.
- `apply_pdf_stamp(pdf_path, output_pdf_path, stamp_img_path, page_num, x, y, width, height)`:
  - Uses PyMuPDF to place visual stamps/signatures on specific PDF coordinates or quadrant presets.
- `merge_pdfs(pdf_list, output_pdf_path)`:
  - Combines main document PDF with attachments/certificates into one unified PDF using `PyMuPDF` or `pypdf`.

#### [NEW] [core/profile_manager.py](file:///e:/@Medi/@002 Gemini Projects/@0001_canido_doc_manager/core/profile_manager.py)
- `save_profile_json(data_dict, file_path)` & `load_profile_json(file_path)`:
  - Serializes and deserializes current 78 variables & image configurations.
- `export_profile_excel(data_list_or_dict, file_path)` & `import_profile_excel(file_path)`:
  - Supports single-profile export or multi-row batch data import/export via `pandas` / `openpyxl`.
- `get_sample_smap_profile()`:
  - Pre-populates standard SMAP default sample data for instant testing.

#### [NEW] [core/batch_worker.py](file:///e:/@Medi/@002 Gemini Projects/@0001_canido_doc_manager/core/batch_worker.py)
- `BatchProcessor`:
  - Utilizes `ThreadPoolExecutor` for non-blocking concurrent replacement across hundreds of `.docx` templates and data rows.
  - Supports progress reporting callbacks (`on_progress(current, total, file_name, status)`), logging, and cancellation.
